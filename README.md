# Course Outline
1. Windows setup

5. Variables
    - *_Store Your Info_*
	Store your name and age in variables and print them.
        - Create a program that asks for your name and age, stores them in variables, and prints a greeting with the info.
6. Data types
    - *_Data Type Sizes_*
	Demonstrate the size of different data types.
        - Write a program that prints the size of int, char, float, and double data types using `sizeof`.
7. printf
    - *_Print Your Bio_*
	Print your name, age, and favorite hobby.
        - Create a program that uses printf to print a short bio with your details.
8. Comments
    - *_Comment Your Code_*
	Add comments to explain your code.
        - Take a previous program and add comments explaining what each part does.
9. Constants
    - *_Circle Area_*
	Calculate the area of a circle using a constant for pi.
        - Define a constant for pi (3.14) and use it to calculate the area of a circle given a radius.
10. Getting user input
