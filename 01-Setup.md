You need two(2) things to start programming in C;

1. An environment where you can write your C programs etc text editor or IDE (Integrated Development Environment) for this course, we use `codeblocks`.

2. 2. A compiler - Should incase you downloaded just a `text-editor`, you would need a `compiler`

# Windows Setup
- Search for `codeblocks` in your browser.
- Click on downloads and go for the binary release and go for OS.
- Go for the `codeblocks` with `mingw` setup, what this does or means is that we can install the IDE (`codeblocks` and also a C compiler).


> [!NOTE] 
>  Install the program
>  Leave the installed setup as default
> set the gnu gcc compiler default or the one highlighted.
